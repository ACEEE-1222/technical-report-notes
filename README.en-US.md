## Notes

- `original/` Stores the originally published technical reports. Copyright belongs to the original authors and publishing organizations.
- `analysis/` Stores the HTML and PDF versions of the Chinese-language analyses.
- The analysis content includes technical judgments based on publicly available materials. When discussing technical origins, it distinguishes between inheritance relationships explicitly disclosed in the reports and inferences based on structural similarities.
