## 分析范围

报告按照原文脉络梳理以下内容：

- KDA、Gated MLA、AttnRes 与 Stable LatentMoE 等模型架构；
- SiTU-GLU、Quantile Balancing、MoonViT-V2 与训练方法；
- FlashKDA、MoonEP、Mooncake、缓存体系与推理基础设施；
- 各项设计的技术谱系，以及“明确继承”和“相关但非直接祖先”的证据边界。
