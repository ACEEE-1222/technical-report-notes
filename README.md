## 说明

- `original/` 保存公开发布的原始技术报告，版权归原作者及发布机构所有。
- `analysis/` 保存中文分析的 HTML 与 PDF 版本。
- 分析内容包含基于公开材料的技术判断；涉及技术来源时，会区分报告明确披露的继承关系与结构相似性推断。
