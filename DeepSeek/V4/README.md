## 分析范围

报告按照原文脉络梳理以下内容：

- DeepSeekMoE、MTP、mHC，以及 Flash 与 Pro 两种配置；
- CSA、HCA、Muon 与百万 token 上下文设计；
- 训练和推理系统、预训练、后训练与 Agent 基础设施；
- 评测结果的适用边界，以及各项设计的技术谱系与证据等级。
